# Internet Speed Test

A simple web app for testing internet connection speed (ping + download).

## Alternative Test File URLs

If you encounter SSL, CORS, or network errors with the default test server, try these reliable alternatives:

- [https://www.httpbin.org/bytes/10485760](https://www.httpbin.org/bytes/10485760) (10MB - recommended)  
- [https://proof.ovh.net/files/10Mb.dat](https://proof.ovh.net/files/10Mb.dat) (10MB - reliable)  
- [https://speed.hetzner.com/10MB.bin](https://speed.hetzner.com/10MB.bin) (Hetzner main domain)  
- [http://ipv4.download.thinkbroadband.com/10MB.zip](http://ipv4.download.thinkbroadband.com/10MB.zip) (HTTP - no SSL)  

> ⚠️ Some servers may have geographical limitations. For best results, pick a server close to your location.
